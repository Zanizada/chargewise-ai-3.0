# Base de conhecimento

Somente arquivos declarados em `manifest.json` são carregados. Síntese GoodWe com
procedência e três documentos escritos para simulação acadêmica; nenhuma tarifa ou
regra condominial deve ser apresentada como oficial. Hash divergente bloqueia ingestão.

O manual oficial HCA restringe reprodução pública. O script
`python -m src.rag.obter_manual` baixa uma cópia para `local/`, ignorada pelo Git,
para leitura local. Não publique o PDF sem autorização. A entrada opcional no manifesto
permite executar o projeto público usando a síntese e o PDF acadêmico de referência.
O PDF acadêmico é renderizado do conteúdo de autoria da equipe, não é manual GoodWe.

Após alterar fontes, revisar gabaritos, atualizar hashes e reingerir. Não alterar fontes
entre experimentos comparáveis. O índice local fica fora do Git e pode ser reproduzido.
